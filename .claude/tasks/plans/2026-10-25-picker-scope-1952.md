## Approach
1. Deny now, ask in a continuation after the hook returned (spike-proven).
2. One dialog function (`scopeDialog`) for both entries, an `everywhere` thunk and a warn key per entry.
3. A hand pick is decided by its own branch in `decideMain`, ahead of every automatic rule; the automatic cap functions stay as they are.
4. The native path stays the only writer of user settings.json (BDR-116).

## Edge cases
- `[1m]` picks: `knownModel` accepts, the pin keeps `[1m]`, the route uses the bare token (BDR-126).
- picker while a dialog is open → deny + toast, no native (R3).
- `$.command.run` rejects on Everywhere → scopeDialog's catch text → logged under `PreModelSwitch picker`.
- `/clear` while the picker dialog is open → stale check → nothing applied (C10).
- hand-picked model marked down → stays on cur with one log; back up → moves (C1/R1).
- `[deferred 2026-10-25]` R3 timeout: a `$.ui.ask` that never settles keeps the slot (no timeout, same as the first-use dialog); picker picks are then denied with the toast (no leak). R7: hand pick lost at `/clear` (BDR-126 residual). R5: `/config` Model row writes user settings (source `command`, indistinguishable from Everywhere's native run).

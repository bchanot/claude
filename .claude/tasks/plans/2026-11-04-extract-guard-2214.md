## Hook flow (bash wrapper)
1. jq or awk missing → one stderr line `extract-guard: <tool> missing, guard inactive`, exit 0.
2. `cmd=$(jq -r '.tool_input.command // empty')`; empty or unparseable → exit 0.
3. Prefilter: `printf '%s' "$cmd" | grep -qE '(^|[^[:alnum:]_.-])(dpkg|dpkg-deb|tar|bsdtar|gtar|unzip|cpio|cp)([^[:alnum:]_-]|$)' || exit 0`.
4. `reason=$(printf '%s' "$cmd" | awk -f <(the program) )` — the program text is a shell variable passed with `awk "$PROG"`; rc ≠ 0 → reason `extract-guard: refused: the checker failed on a command that names <first watched word>; run it yourself if it is safe: ! <command>` (fail closed only past the prefilter).
5. Non-empty reason → print the deny JSON with `jq -n --arg r "$reason" '{hookSpecificOutput:{hookEventName:"PreToolUse",permissionDecision:"deny",permissionDecisionReason:$r}}'`, exit 0; else exit 0 silently. Exactly one JSON object (test: two violations in one command → `jq -s length` is 1).

## The awk program
- `scan(text, depth)`: tokenizes `text` into records and words; `depth > 3` with a watched word → deny `nesting too deep`.
- Tokenizer (adapted from hooks/push-guard.sh `simple_cmds` at fe7d5cd, the adaptations named in a comment): quotes removed with their content kept in the word, INCLUDING newlines (a newline inside quotes never ends a record); `\`+newline folded; records end at unquoted `;`, `&&`, `||`, `|`, `&` (not part of `>&`, `&>`, `2>&1`), newline, `(`, `)`; `<<<` is a redirection operator (no heredoc); `<<`/`<<-` reads a delimiter and the heredoc BODY text is passed to `scan(body, depth+1)` whatever command owns it; `$(…)` (balanced) and backticks: the inner text goes to `scan(inner, depth+1)` and the outer word keeps a literal `$` marker so a destination built from it is unresolvable; `#` at a word start (unquoted) starts a comment to end of line.
- Re-scan rule: every word that contains a blank or a newline (it came from quotes) is also passed to `scan(word, depth+1)` — no carrier list (covers `ssh … '…'`, `vaas-cli ssh … '…'`, `bash -c '…'`, `sudo sh -c "…"`, `timeout 9 ssh …`, `find -exec sh -c '…'`, multi-line scripts).
- Flood: more than 5000 records or 300 re-scans in total → deny `command too large to check`.
- Per record: drop redirection words (`>`, `>>`, `<`, `2>`, `&>`, `>&2`, `2>&1`, `>file`, `2>/dev/null`) and the word after a bare operator; drop find terminators `;`, `+`, `\;` and `{}`; track `cd`/`pushd` (options `-P -L --` skipped) → `DIR` (relative target joined to the previous `DIR`; empty `DIR` + relative → stays empty; `~`/`$HOME` targets → home; `cd -`, bare `cd`, `popd` → empty). `DIR` is per scan level (a nested scan starts with the caller's `DIR` and does not change it).
- For every word position k whose basename is a watched tool, run its detector on the words after k (this one rule covers wrappers `sudo`, `nice -n 10`, `stdbuf -oL`, `busybox`, `xargs`, `find -exec`, and argv-form remotes `vaas-cli ssh vm -- …`, `ssh vm sudo …`).
- Bundle = a word matching `^-[A-Za-z]+$`.
- Detectors (collect every destination; refuse if any is system or unresolvable):
  - tar/bsdtar/gtar: extract when a bundle contains `x`, or the first word after the tool matches `^[A-Za-z]+$` and contains `x` (old style), or a word is `--extract` / `--get`; never when a bundle or the old-style word contains `t` or a word is `--list`. Destinations: `-C <d>`, `-C<d>`, a bundle ending in `C` takes the next word, `--directory <d>`, `--directory=<d>`.
  - dpkg / dpkg-deb: a word `-x`, `-X`, `--extract`, `--vextract` (dpkg-deb also `-R`, `--raw-extract`); destination = the second non-option word after it; absent → refused.
  - unzip: listing when a bundle contains `l`, `v`, `t`, `Z` or `z` → no verdict; destination `-d <d>`, `-d<d>`, a bundle ending in `d` takes the next word.
  - cpio: extract when a bundle contains `i` and no `t`, or `--extract`; destination `-D <d>`, `-D<d>`, `--directory <d>`, `--directory=<d>`, a bundle ending in `D` takes the next word.
  - cp: recursive when a bundle contains `r`, `R` or `a`, or `--recursive` / `--archive`; destination `-t <d>`, `-t<d>`, a bundle ending in `t` takes the next word, `--target-directory <d>`, `--target-directory=<d>`, else the last non-option word of the record.
  - An extraction with no destination option → the destination is `DIR` when set, else no verdict (local and remote alike).
- `is_system(p)`: `~` / `~/…` / `$HOME` / `${HOME}` prefixes → replaced by `/HOME`; any other `$` or backtick → unresolvable; relative → joined to `DIR` when set, else not system; normalize (collapse `//`, drop `/.`, resolve `..`, trailing `/` stripped while length > 1); `/HOME` and below, `/var/tmp`, `/var/folders` and below → not system; system when `/` or under `/usr /etc /bin /sbin /lib /lib32 /lib64 /libx32 /boot /opt /var /srv /root /sys /proc /dev`.
- Reason text: `extract-guard: refused: <tool> writes into system directory <dest> (CLAUDE.md "Destructive tools & data loss"). List it first (dpkg -c, tar tf, unzip -l), run mktemp -d alone and extract into the literal path it prints, then use PATH or PYTHONPATH; a real system install is the user's: ! <command>`; unresolvable: `… destination <dest> cannot be checked; write the literal path`.

## soft_deny line (settings.json autoMode.soft_deny, appended)
`Extracting, unpacking or recursively copying a package or an archive into / or a system directory (/usr, /etc, /bin, /sbin, /lib*, /boot, /opt, /var, /srv, /root), on this machine or on a remote machine or VM (ssh, vaas-cli ssh, a script it runs): refuse; list the archive, extract into a work dir and use PATH or PYTHONPATH, or tell the user there is no package manager.`

## Doctrine bullet (CLAUDE.global.md, after the lftp bullet)
```
- Installing a package or an archive on a machine or a VM never extracts it
  (`dpkg -x`, `tar x`, `unzip`, `cpio -i`, `cp -r`) into `/`, `/usr`, `/etc`
  or another system directory: on usr-merge distributions `/bin`, `/sbin`,
  `/lib`, `/lib64` are symlinks that an archive carrying those paths
  replaces with real directories. List it first (`dpkg -c`, `tar tf`),
  extract into a literal `mktemp -d` path and use PATH or PYTHONPATH; no
  package manager on the target → say so to the user, never improvise.
  `hooks/extract-guard.sh` refuses these commands.
```

## MISSES (header comment)
A destination built at runtime outside the text (script file, Makefile, alias, variable set in an earlier call); option values swallowed by the "watched word anywhere" rule; old-style tar `C` letter (`tar xfC a.tar /usr`), getopt_long abbreviations (`--dir=`), `--one-top-level=`; archive members escaping a safe `-C` (`../../usr`, `-P`) — the doctrine's "list first" covers them; an extraction with no destination run from a remote shell whose cwd is a system dir. The soft_deny line is the net for these.

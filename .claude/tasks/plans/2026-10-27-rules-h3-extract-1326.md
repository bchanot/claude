## Approach
- The heading argument carries its level: bare `<title>` = `## <title>`
  (unchanged, including a title that starts with `#` such as `#1 priority`);
  `### <title>` = a level-3 section; `## <title>` is accepted as the explicit
  level-2 form. `# x` (H1) or `####`-and-deeper → rc 2 `heading level must
  be ## or ###`. One helper
  `_rules_heading_line` normalises the argument to the exact heading LINE;
  every awk helper takes that line and derives the level inside awk as
  `lvl = index(h, " ") - 1`.
- A section of level L ends at the next heading of level ≤ L outside a
  fence: awk test `match($0, /^#+ /) && RLENGTH - 1 <= lvl`.
- Separator rule, level 3 ONLY: when a `###` section is removed and its end
  is a heading of a LOWER level (`#`/`##`), the trailing run of blank/`---`
  lines it carried is re-emitted in the source (it was the parent's closing
  separator); when the end is a same-level heading, the run goes with the
  section. A `##` section keeps today's behaviour exactly (its run always
  travels with it, an H1 end included): the awk condition is
  `lvl == 3 && RLENGTH - 1 < lvl`. The rule body trims the run either way.
- `sections [--depth 2|3] <file>`: depth 2 is today's output byte for byte;
  depth 3 also lists each `###` subsection (its own chars, its line, the
  `### <title>` heading). A `##` parent's chars keep counting through its
  children (same number as depth 2). Exactly one positional argument after
  the optional flag, else rc 2 (a flag after the file is an error, not a
  silent depth 2). Lines come out in file order: awk prints at close, so the
  output is piped through `sort -t "$(printf '\t')" -k2,2n`.
- Rule title line: `# <title without its prefix>`.

```bash
_rules_heading_line() {  # <heading arg> → "## t" | "### t" on stdout, rc 2
  case "$1" in
    '## '*|'### '*) printf '%s\n' "$1" ;;
    '# '*|'####'*)
      echo "project-rules: heading level must be ## or ###: $1" >&2
      return 2 ;;
    *) printf '## %s\n' "$1" ;;
  esac
}

_rules_heading_count() {  # <file> <heading line> → fence-aware count
  awk -v h="$2" '/^```/ { fence = !fence }
                 !fence && $0 == h { n++ }
                 END { print n + 0 }' "$1"
}

_rules_section_body() {  # <file> <heading line> → body, ---/blank trimmed
  awk -v h="$2" '
    BEGIN { lvl = index(h, " ") - 1 }
    /^```/ { fence = !fence }
    !fence && $0 == h { on = 1; next }
    !fence && on && match($0, /^#+ /) && RLENGTH - 1 <= lvl { exit }
    on { buf[++n] = $0 }
    END { while (n > 0 && (buf[n] == "" || buf[n] == "---")) n--
          for (i = 1; i <= n; i++) print buf[i] }' "$1"
}

_rules_without_section() {  # <file> <heading line> → the file minus it
  # a ### ended by a lower-level heading gives its trailing ---/blank run
  # back to the source (the parent's closing separator); a ## keeps today's
  # behaviour, its run travels with it
  awk -v h="$2" '
    BEGIN { lvl = index(h, " ") - 1 }
    /^```/ { fence = !fence }
    !fence && $0 == h { skip = 1; n = 0; next }
    !fence && skip && match($0, /^#+ /) && RLENGTH - 1 <= lvl {
      if (lvl == 3 && RLENGTH - 1 < lvl) for (i = 1; i <= n; i++) print buf[i]
      skip = 0 }
    skip { if ($0 == "" || $0 == "---") buf[++n] = $0; else n = 0; next }
    { print }' "$1"
}
```
(`'####'*` without a trailing space catches every level ≥ 4.)

`project_rules_sections` becomes:
```bash
project_rules_sections() {  # [--depth 2|3] <file> → chars, line, heading
  local depth=2
  if [ "${1:-}" = "--depth" ]; then depth="${2:-}"; shift 2; fi
  case "$depth" in 2|3) ;; *)
    echo "project-rules: --depth takes 2 or 3" >&2; return 2 ;; esac
  [ $# -eq 1 ] \
    || { echo "project-rules: sections [--depth 2|3] <file>" >&2; return 2; }
  [ -f "$1" ] || { echo "project-rules: $1 not found" >&2; return 2; }
  awk -v depth="$depth" '
    function flush2() {
      if (h2 != "") printf "%d\t%d\t%s\n", c2, l2, h2; h2 = "" }
    function flush3() {
      if (h3 != "") printf "%d\t%d\t%s\n", c3, l3, h3; h3 = "" }
    /^```/ { fence = !fence }
    /^# / && !fence { flush3(); flush2() }
    /^## / && !fence { flush3(); flush2(); h2 = $0; l2 = NR; c2 = 0 }
    /^### / && !fence && depth == 3 { flush3(); h3 = $0; l3 = NR; c3 = 0 }
    h2 != "" { c2 += length($0) + 1 }
    h3 != "" { c3 += length($0) + 1 }
    END { flush3(); flush2() }' "$1" | sort -t "$(printf '\t')" -k2,2n
}
```
(`shift 2` with a lone `--depth` and `set -u`: `${2:-}` is empty, the case
refuses it before the shift matters; if shellcheck or bash complains about
`shift 2` on one argument, guard with `[ $# -ge 2 ] &&`.)

`project_rules_extract` becomes (locals: src out globs hline tmp):
```bash
project_rules_extract() {  # <file> <heading> <out.md> <globs-json>
  local src="$1" out="$3" globs="$4" hline tmp
  hline=$(_rules_heading_line "$2") || return 2
  [ "$(_rules_heading_count "$src" "$hline")" = 1 ] || {
    echo "project-rules: heading must occur exactly once: $hline" >&2
    return 2; }
  [ -e "$out" ] && { echo "project-rules: $out exists" >&2; return 2; }
  _rules_globs_all_match "$globs" || return 2
  mkdir -p "$(dirname "$out")"
  tmp=$(mktemp) || { echo "project-rules: no temp file" >&2; return 2; }
  { printf -- '---\npaths: %s\n---\n\n# %s\n' "$globs" "${hline#* }"
    _rules_section_body "$src" "$hline"; } > "$out"
  if ! { _rules_without_section "$src" "$hline" > "$tmp" \
         && cat "$tmp" > "$src"; }; then
    rm -f "$tmp" "$out"
    echo "project-rules: $src not rewritten, $out removed" >&2
    return 2
  fi
  rm -f "$tmp"
  echo "project-rules: moved '$hline' to $out"
}
```

## Edge cases
- `### ` inside a fence: never a heading (fence-aware, T13i).
- `####` under a `###`: body of the `###` (T13i/T13j), not extractable (T13p).
- Same `###` title under two parents: count 2 → rc 2, user renames (the
  existing "exactly once" rule, now across levels).
- Last `###` of a parent: the parent's trailing `---` stays in the source
  (T13l/T13m); a same-level end takes the run with the section, as `##`.
- `sections --depth 3` on a file with no `###`: identical to depth 2.
- A bare title starting with `#` (`#1 priority`): still `##` (T13u).
- `sort` on an empty awk output: prints nothing, rc 0.
